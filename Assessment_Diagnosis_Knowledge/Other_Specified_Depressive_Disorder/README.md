# Other specified depressive disorder — adult assessment knowledge

Start with the [readable guide](../07_Other_Specified_Depressive_Disorder_Assessment.md). Adults 18+, including older adults.

The package contains 29 concept cards and 16 sources. `classification_reference.json` describes four named examples, their different requirements and source issues. It is not a classifier. `knowledge.json` defines role-relevant domains, fields and values; `evidence_output.schema.json` defines patient output. `examples.json` holds authored fictional snapshots, not live LLM results.

Run only the mechanical checks from this folder (Python and jsonschema required):

```powershell
python validate_package.py
```

Results: `VALIDATION_REPORT.json`. No API key is needed and no interview/model call is performed. Clinical review, source-boundary clarification, final cross-disorder graph and runtime integration remain pending. Later integration should select relevant role-specific context rather than send the entire package every turn. Unknown criteria are not unmet criteria; no diagnostic conclusion is generated by these checks.
